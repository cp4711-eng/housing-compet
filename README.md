# housing-compet
Chayanunt Payapvattanavong
Ames Housing Price Prediction

This project explores house price prediction using the Ames Housing Dataset from Kaggle's Regression for House Prices competition.

The project uses housing features such as overall quality, living area, number of bedrooms, garage size, and year built to analyze factors influencing house prices and build predictive regression models.

Using Python, I perform data cleaning, exploratory data analysis, feature selection, and model building.

Tools & Libraries: Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Seaborn.
